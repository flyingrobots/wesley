# Wesley v0.3.0-alpha.2

## Summary

Wesley `0.3.0-alpha.2` makes `wesley-core` cheap to embed. The compiler kernel
is synchronous and pure, but every consumer used to inherit an async runtime
stack. A consumer that only lowers, hashes, or diffs SDL can now opt out of it.

This is the second pre-release of the 0.3.0 line. APIs, the CLI surface, and
emitted artifacts remain unstable and may change before the stable `0.3.0`.

## What Changed

- `wesley-core` gains a `resilience` feature, **on by default**. It carries the
  async `LoweringPort`, its `ApolloLoweringAdapter` implementation, and the
  `ninelives`-backed `ResilientLoweringPort` with `ResiliencePolicy`.
- Two unused `wesley-core` dependencies are removed: `tower`, which no source
  file referenced, and the normal `tokio` dependency with every feature enabled,
  which only tests used.
- `cargo xtask lean-core-check`, part of `cargo xtask preflight`, tests
  `wesley-core` without default features and fails if that build's dependency
  tree names `async-trait`, `ninelives`, `tokio`, or `tower`.

| `wesley-core` normal dependency tree | Before | After |
| ------------------------------------ | -----: | ----: |
| default features                     |     90 |    77 |
| `default-features = false`           |     90 |    44 |

## Why It Matters

`lower_schema_sdl`, `normalize_schema_sdl`, `diff_schema_sdl`, the hashing
functions, and operation analysis need no runtime. A build-time tool that calls
only those should not compile an async runtime to do it. With the feature off,
such a tool compiles about half as many crates and inherits no async stack to
audit.

## Breaking Changes

None for default-feature consumers: the public API is unchanged, and
`WesleyError` keeps the same variants in both configurations.

`--no-default-features` used to change nothing, because `wesley-core` declared
no features. It now removes `LoweringPort`, `ResilientLoweringPort`, and
`ResiliencePolicy`. A consumer that already passed that flag and uses those
types must enable `resilience`.

## Migration

To omit the async runtime stack:

```toml
wesley-core = { version = "0.3.0-alpha.2", default-features = false }
```

To keep the async port while disabling defaults:

```toml
wesley-core = { version = "0.3.0-alpha.2", default-features = false, features = ["resilience"] }
```

No change is needed otherwise.
