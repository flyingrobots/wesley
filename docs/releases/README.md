# Releases

Store user-facing release notes here.

## Release Notes

- [Wesley v0.0.5](./v0.0.5.md)
- [Wesley v0.0.4](./v0.0.4.md)

Each release note should live at `docs/releases/vX.Y.Z.md` and include these
sections in order:

1. Summary
2. What Changed
3. Why It Matters
4. Breaking Changes
5. Migration
6. Links to deeper docs

If there is no upgrade work for users, say `No migration required.` explicitly
instead of leaving the migration section empty.

`CHANGELOG.md` remains the historical ledger. These docs are the guided release
surface for humans and agents adopting a release.
