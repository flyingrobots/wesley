# Holmes Dashboard Choose Your Track Orientation

Implement a formal 'Choose Your Track' orientation in the Holmes dashboard using the Bijou-TUI TEA pattern. The release witness is that an operator can enter the dashboard and intentionally choose the database-change, Continuum-contract, or governance track instead of starting from an undifferentiated control surface.
