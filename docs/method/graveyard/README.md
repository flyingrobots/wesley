# Graveyard

Rejected or retired work lives here.

Use this directory when a design path, backlog idea, or temporary spike should
not be quietly re-proposed without context.

Each note should answer:

- what was rejected or retired
- why it was rejected or retired
- what would need to change before reopening the idea

The graveyard is not a shame pile. It is a memory surface that keeps old ideas
from coming back as if they were new.
