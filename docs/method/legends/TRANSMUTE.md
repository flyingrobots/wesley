# TRANSMUTE

## Scope

`TRANSMUTE` covers Wesley's artifact-domain expansion: transmutation
declarations, generators, output contracts, and the mapping from source schemas
into multiple executable artifact families.

## Guards

- `schema-source-of-truth`
- `governance-boundaries`
- `docs-runtime-honesty`

## Standing playback questions

- Can a declared transmutation map explicit inputs to explicit generators and
  outputs without hidden coupling?
- Can Wesley expand into a new artifact domain without breaking source
  authority or forcing one transmutation's assumptions onto another?
