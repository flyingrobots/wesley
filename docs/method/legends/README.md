# Legends

Legends organize attention across many cycles. They are not milestones.

Wesley currently uses:

- [SOURCE](./SOURCE.md)
- [TRANSMUTE](./TRANSMUTE.md)
- [RUNTIME](./RUNTIME.md)
- [EVIDENCE](./EVIDENCE.md)

Each legend names what it covers, which invariants it guards, and the standing
playback questions it keeps alive.

These legends are application domains, not product pillars and not invariants:

- pillars say what Wesley is trying to be
- invariants say what must remain true
- legends say where enduring work tends to live
