# Wesley Error Taxonomy And Versioned Holmes Codes

Standardize Wesley error reporting so every HOLMES policy failure resolves to a stable, versioned error code with a documented category. The release witness is that dashboard, CLI, and CI surfaces can report policy failures without freehand phrasing drift.
