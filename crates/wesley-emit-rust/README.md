# wesley-emit-rust

Part of [Wesley](https://github.com/flyingrobots/wesley#readme). Emits Rust source from Wesley's L1 IR.

```rust
let ir = wesley_core::lower_schema_sdl(sdl)?;
let operations = wesley_core::list_schema_operations_sdl(sdl)?;

let models = wesley_emit_rust::emit_rust(&ir);
let with_bindings = wesley_emit_rust::emit_rust_with_operations(&ir, &operations);
```

`emit_rust` gives a `serde` struct for each type. `emit_rust_with_operations`
adds, for each root operation, a request type, a response alias, and metadata
constants. The crate also emits little-endian binary codecs from the plan in
`wesley-emit-codec`. The `wesley emit rust` and `wesley emit le-binary-rust`
commands are this crate behind a command line.

The output begins with `// @generated by Wesley. Do not edit.` and is
deterministic: the same IR gives the same bytes.

Wesley is pre-1.0. Emitted code may change between releases. Apache-2.0.
